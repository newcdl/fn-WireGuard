## 安装

在飞牛 **应用中心 → 手动上传应用** 中选择对应架构的安装包：

| 文件 | 适用架构 | 确认方式 |
|---|---|---|
| `fn-wireguard-1.0.0-amd64.fpk` | x86_64（Intel / AMD） | `uname -m` 输出 `x86_64` |
| `fn-wireguard-1.0.0-arm64.fpk` | ARM64 | `uname -m` 输出 `aarch64` |

> 系统要求 fnOS ≥ 1.1.3100（低于此版本应用中心会直接拒绝安装）。
> 使用前请在路由器上把 WireGuard 端口（默认 UDP 51820）转发到 NAS 的局域网地址。

## 更新内容

### 新增功能

1. **网络拓扑图**：以本机 NAS 为中心画出所在内网及其设备、连上隧道的设备、以及经隧道连到的另一台 NAS 及其内网；节点可拖动并记住位置，支持放射 / 环状 / 自由三种布局，单击高亮整条链路、双击跳到对应页面、右键复制地址或去处理，带全览缩略图与一键导出 PNG，连线按实时速率流动
2. **按设备限制内网目标**：单台设备可指定能访问家里的哪些目标（可细到 `192.168.1.10:445`），限制落在服务端转发规则上，设备改不了
3. **内网资产台账**：跟着每次巡检记录内网设备（地址、MAC、名称、类型、首次与最近出现、累计天数），出现新设备时写审计并推送通知，确认后不再提醒
4. **配置漂移巡检**：按日程把实际状态与你的配置对一遍并写成报告（后台服务、运行模式、上网路线、连接工作状态、隔离与访问控制、残留网卡、对外地址、通知、域名解析、计划备份等逐项给结论），查出问题推送通知，报告保留最近若干份
5. **一键诊断包**：把体检、巡检、拓扑原始数据、资产台账、连接与设备清单、运行记录与审计打包成一个 tar 下载（浏览器端打包、不上传），出问题时发一个文件即可
6. **流量报表与每月额度**：每分钟把每台设备的累计流量记账并按小时落库，按设备 / 按天查看用量与趋势（近 7 / 30 / 90 天）、导出 CSV；可给单台设备设每月发送上限，用满自动停用并通知、月初自动恢复
7. **计划备份到授权共享文件夹**：按日程（每天 / 每周 + 时刻）把完整备份写到你授权的共享目录并只保留最近若干份，保存时实际探测目录可写，错过的时间点开机后补跑，失败推送通知，可从副本直接下载或还原
8. **两种列表视图**：所有列表都能在右上角切成表格或卡片，卡片在电脑上按宽度自适应分列、手机上一条一行，选过一次即记住
9. **以飞牛账号登录**：从飞牛桌面点开应用后，登录页给出「飞牛账号」按钮，点一下即用飞牛身份进入；按飞牛账号 UID 建号（用户名优先取飞牛用户名、重名加后缀，绝不复用已有账号），角色随每次登录同步，这类账号没有本应用口令因此不能走密码登录
10. **敏感操作二次验证**（默认关）：开启后，以飞牛账号登录的身份在查看本机密钥、用备份还原、管理账号前需输入一次动态口令，验证后 10 分钟内有效；用账号密码从端口进入时不受影响。开启前会先确认当前账号已绑定二次验证
11. **二维码**改为圆点样式并统一带应用图标（纠错等级 H，实测在 720 / 1080 两种尺寸下均可扫）
12. **登录页重新设计**：桌面端双栏（品牌栏 + 表单）、窄屏单栏，输入框与主按钮加大，明暗主题各自适配
13. **初始化可选「不建本地账号，直接用飞牛账号登录」**：本地不落任何口令，第一位管理员就是发起初始化的那个飞牛账号，应急安全码照发；初始化页整体重做（品牌头 + 两枚选项卡式选择按钮，窄屏单列），并补上「飞牛账号可以直接登录」的说明

### 修复问题

1. 未配置对外地址时，设备列表误报「需重新扫码」且点不掉
2. 首次打开「开启二次验证」时二维码区域是空白：现在没生成出来会明确说明并给出「重新生成二维码」，同时给图标准备加了超时兜底，不再以「少个装饰图标」换「整块不可用」
3. 列表操作列的「更多」下拉比旁边按钮偏高一点点（现统一对齐）

### 其它

1. 依赖：无新增；二维码、图表、拓扑渲染均使用既有依赖
2. 服务端新增 `sys_user.trim_uid` 列（部分唯一索引）与网关相关设置项，随既有迁移流程自动生效
3. 用户协议与免责声明：随包分发的《用户协议与隐私说明》补充了免责条款（严禁用于违法用途、使用者自行承担全部责任、作者不承担连带责任、按现状提供且不附担保），README 增加「法律与免责」一节，应用内「系统设置 → 关于」也能直接读到要点
4. 文档与截图：README、路线图与应用介绍同步更新，界面截图重拍并补充了登录页、网络拓扑、流量报表与卡片视图
