# 界面截图

主 [README](../../README.md) 的「界面预览」一节引用这里的图片。**文件名必须与下表一致** ——
README 里写的就是这些名字，改名字要同时改 README。

## 需要补齐的文件

| 文件名 | 拍哪一页 | 画面里最该出现的东西 |
|---|---|---|
| `overview.png` | 总览 | 连接与设备状态、实时流量曲线、系统状态卡 |
| `interfaces.png` | 我的连接 | 一条连接的地址/端口、DNS，以及内网访问与设备隔离开关 |
| `peers.png` | 我的设备 | 设备列表（含在线状态）、二维码入口、期限与配额 |
| `maintenance.png` | 系统维护 | 一键体检结论、逐项自检（内网访问那一组），有异常项的更好 |
| `settings-notify.png` | 系统设置 → 事件通知 | Webhook 地址、推送格式、逐事件开关、「发送测试通知」 |
| `dark.png` | 深色外观下的任一页 | 建议与 `overview.png` 同一页，方便对比深浅两套配色 |

可选补充（README 暂未引用，需要时再加一行）：

| 文件名 | 用途 |
|---|---|
| `login.png` | 登录页（可与首次初始化的「设置管理员账号 + 应急安全码」合成一张） |
| `setup.png` | 首次初始化的三步向导 |
| `snapshot.png` | 系统设置 → 配置快照，含「回滚会撤销什么」的差异清单 |

## 拍摄约定

- **尺寸**：桌面端截图窗口宽度取 1280px 左右，导出后按 2 倍图存放（`width="460"` 显示时会自动缩放）；
  手机端截图单独存，不要和桌面端混在一张里。
- **格式**：PNG，单张控制在 300KB 以内（`pngquant` 或 `oxipng` 压一道；带缓存的界面里纯色区块多，通常压得很小）。
- **深浅一致**：同一批截图要么全浅色、要么全深色，只有 `dark.png` 例外 —— 混着放会让 README 显得凌乱。
- **不含真实数据**：截图前把公网地址、域名、设备备注、密钥、二维码换成示例值，或用测试连接；
  **不要出现真实的公网 IP、DDNS 域名、WireGuard 公钥与二维码** —— 截图会随仓库长期公开，
  二维码里就是配置本身。
- **不加设备边框与阴影**：README 里是并排两列，自带边框会让两列看起来不齐。

## 怎么截

浏览器窗口调到 1280×800 左右，用开发者工具的设备模拟或系统截图工具整窗截取；
需要在图上指出的地方（例如右上的外观切换按钮），用细线框 + 箭头标注，不要用大面积高亮色块。
